# 运动搭子审片意见

本文件记录用户转交的独立审片最终意见，以及 Codex 的采用情况。原审片人核对了视频抽帧、元数据、响度、封面和发布文案，未试听。涉及声音的原意见均为波形推断。

## 原审片必改

1. 全片和封面的“推门就跑”与视频中缺少推门、跑步镜头不符。推荐方案 A，改为“说好来海边运动 / 他只动了嘴”，同步改小红书标题和文案。
2. 原约12–17秒重量对白配跑步机、榻榻米，缺哑铃。若无法补清晰特写，整组两句删掉。
3. 原约19–20.2秒“配合你，练了一路口才”字幕可能比人声早约1.2秒，需核对实际声音并对齐。
4. 四平台正文中的“最奢侈的运动搭子，是一片海”“哑铃放下，推门就跑”等与故事不符，按运动搭子只动嘴的主题重写。

## 原审片建议

- 片尾品牌字叠树叶不清楚，放到深底框；裁掉垃圾桶；结尾改为“运动搭子到位，嘴先热身”。
- 角色、小标签和字幕框三层遮挡，减少叠加。
- 沙滩段缺人物运动参照，可补能看出站着不动的镜头。
- 无对白处配乐可能偏低，需实际试听后判断。
- 原11.75–12.5秒健身房入场停顿偏长，收紧。

## v3 已采用

- 采用方案 A，封面、标题和四平台正文统一主题。
- 删除两句重量对白及对应镜头，保留正常语速，新版总时长约21.32秒。
- “配合你”和“练了一路口才”拆成两个字幕随各自语段显示，中间停顿收紧。原始波形显示前半句已在句首发声，后半句在约1.2秒开始；按两段实际发声重排，未把波形分析说成试听。
- 片尾品牌加深底框，画面裁掉右侧区域以避开蓝桶，结尾改为“运动搭子到位，嘴先热身”。
- 去掉角色标签和“嘴强王者，正式上线”的重复小标签。
- 开头补已有沙滩人物走动实拍。“站着喘”处用摄影师影子短定格，提供画面参照。
- 保留用户指定《海风轻拂》，无对白时背景目标响度从-28提高到-25 LUFS，对白时自动压低。
