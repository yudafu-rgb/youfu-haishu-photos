# 来源

这个技能原样取自 Matt Pocock 的 skills 仓库（MIT 许可，许可全文见同目录 LICENSE）：
https://github.com/mattpocock/skills/tree/5beb35b040e3de97e54fa9e386d7e42d15c295c2/skills/productivity/to-questionnaire

用法：在 Claude Code 里输入 `/to-questionnaire`，说明要发给谁、需要对方回答什么，
它会在仓库根目录生成一份 `to-questionnaire-<主题>.md` 问卷，发给对方填写。
只放了这一个技能，没有装整包。
