福州吃喝玩乐攻略

来琅岐岛之前，先在福州市区吃一圈、逛一圈。这是我们给客人整理的路线和吃法；岛上怎么玩，看琅岐岛攻略。

福州48小时吃什么

福州两天怎么吃：按片区安排锅边、海蛎饼、捞化、芋泥、闽菜、牛滑、拌面扁肉和传统糕点，附交通和点单小抄，最后留一天去琅岐岛看海。

福州3天2晚怎么排

第一次来福州 3 天怎么安排：三坊七巷和朱紫坊、烟台山和闽江边、福建博物院和西湖，每天留多久、怎么去，想加福道怎么替换。

福州8处低预算漫步地

福州不花门票也能逛：三坊七巷、上下杭、烟台山、福道、福建博物院、西湖公园、朱紫坊、闽江之心，每处留多久、和谁搭着走、哪些项目另收费。

福州周末去哪：先选山还是海

福州周末备选：市区西禅寺、乌山，山里的鼓岭，海边的琅岐龙鼓，连江奇达村、永泰嵩口古镇、福清大姆山、马尾闽安古镇，按玩法和交通挑一个。

福州2天慢游

福州两天慢慢玩：第一天烟台山、闽菜和闽江边，第二天朱紫坊和上下杭；下雨换福建博物院；多一天就去琅岐岛海边。
